# Proof

Every number below is generated by `bun run eval` (`eval/evaluate.ts`) from a recorded run's event rows and the separate answer key; nothing is typed in by hand. Each section names the run, the commit and the detector it ran on.

- **Detection code is frozen.** The tag `detector-frozen` is on commit `f40ff3b` (2026-10-25, 02:45 PT). It was first set on `ea57806` at 02:22 and moved once, to add the verification sweep (#48), before anyone had run or seen seed 99. `bun run hazel` refuses a held-out seed on any other detection code.
- **Seed 13** is the development portfolio: the team saw its patterns while building, so it shows the system working, not generalising.
- **Seed 99** is the held-out set, written by C, who wrote no detection code; A and D did not open its spec or answer key until its proof run was done. It was run once, on the frozen code (`r99-20261025T102031`), and is reported as it came out. Its spec is now `data/patterns/seed99.json`: two rings instead of one, and two of most lookalike patterns.
- **One run per agent.** Hazel chooses her own path, so her figures vary from run to run. Seed 13 runs found the same 6 of 6 ring members with 0 innocents flagged every time; the acorns at which the ring was complete varied: 7, 9, 10, 12 and 14.
- **Acorns.** Hazel's total includes the verification sweep: with no lead left, code spends the rest of the budget checking the largest unverified balances. The line under each table gives the acorns at which her ring was complete.
- **Other loans flagged.** The 1 in seed 13 is L0742, held as Investigate while its question to the CRO is open (a 684-staff employer shared by 2 loans). It is cleared once the CRO answers on the CRO screen.
- **Review cases.** Hazel reaches them only through the sweep, by balance. On both seeds it reached 1 of 3; the others were not among the largest balances. Check everything gets all 3 because it checks every loan.

Hazel's ring members were all marked Investigate after **14 acorns**; the other 45 went on her remaining leads and the verification sweep (when no lead is left, code spends the rest checking the largest unverified balances).

- **Ring found:** ring members marked Investigate. **Innocents flagged:** lookalikes (a shared building, household, employer
  or dealer burst with an innocent explanation) and risky-but-real loans marked Investigate. **Other loans flagged:** any
  other loan marked Investigate. **Review cases right:** fraud alert, frozen bureau and bureau disagreement cases with
  their expected status.
- **Check everything** runs all four CRS products on every loan with no budget; statuses come from the CRS answers alone.
- **Fixed rules** flags every loan sharing a phone, email, bank account, device, IP address or street address with another loan, then spends the
  same budget as Hazel (60 acorns) on identity checks, flagged loans first.
- Acorn prices are design choices (`lib/contracts/tool-result.ts`); each shows its real unit there. A loan an agent never
  gave a status counts as not flagged.
