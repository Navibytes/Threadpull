# Proof

Every number below is generated by `bun run eval` (`eval/evaluate.ts`) from a recorded run's event rows and the separate answer key; nothing is typed in by hand. Each section names the run, the commit and the detector it ran on.

- **Detection code is frozen.** The tag `detector-frozen` (commit `ea57806`) was created on 2026-10-25 at 02:22 PT, after tickets 07, 08 and 11 were merged. `bun run hazel` refuses a held-out seed on any other detection code.
- **Seed 13** is the development portfolio: the team saw its patterns while building, so it shows the system working, not generalising.
- **Seed 99** is the held-out set, written by C, who wrote no detection code. Nobody who did saw it before this freeze. Its results are pending: it is run once, on the frozen code, and reported as it comes out.
- **One run per agent.** Hazel chooses her own path, so her figures vary from run to run. Pre-freeze runs of seed 13 found the same 6 of 6 for 10 and 12 acorns.
- **Review cases.** In this run Hazel never reached them: P16 fraud alert, P15 frozen bureau, P17 bureau disagreement. A loan an agent never gave a status counts as not right, so she scores 0 of 3. Check everything scores 3 of 3 because it pays to check every case loan.
